## What was built
- `scripts/simulation/power_grid.gd`: typed GDScript, `extends RefCounted`, no scene tree / autoload / OS / Time / random access
  (enforced by a source-scan test). Definition loading + validation (INVALID_ID, DUPLICATE_ID, BAD_KIND, BAD_VALUE, MISSING_FIELD,
  UNKNOWN_NODE, SELF_LOOP, SOURCE_BACKFEED, CONSUMER_OUTPUT, CYCLE, DUAL_SUPPLY), evaluation steps 1-5 in stable ID order, commands
  (`set` / `add_edge` / `remove_edge`) validated on the trial state and rolled back on refusal, canonical serializer + SHA-256.
- `content/contracts/c01_alder_street/grid.json`: C01 network (11 edges, 12 nodes). Service-drop capacities = demand (choice, ADR-003 addendum 5).
- `tests/data/c01_grid_cases.json`: 11 command scenarios + 7 invalid definitions, shared by both implementations.
- `reference/lbo_grid.py`, `reference/cases.py`, `reference/tests/test_grid.py`.
- `tools/cross_check_reference.py` + `tools/godot/dump_grid_cases.gd`: replay every case forwards and with reversed input order on both sides,
  compare outcome + hash after every command and the final canonical string; skips with a message if `reference/` is absent.
- `tools/validate_content.py`: rejects non-integer numbers in `content/` (Godot reads all JSON numbers as float).
- `tools/run_tests.sh` now runs content validation and the cross-check too.
- ADR-003 addendum: exact state field list and 8 interpretations (edge active, blocked junction, live edge, dual supply, cycles on the
  potential graph, drop capacities, command set, integer loading).
