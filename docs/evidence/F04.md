## Acceptance criterion (copied from docs/backlog.json)

## What was built
`scripts/network/connection_flow.gd`: client lifecycle idle -> connecting -> handshake -> joining -> in_session, with reconnect_wait and ended;
deadline on every non-final state; end states carry one reason code and the offered actions (retry / back / play_offline / update_game).
Offline solo goes straight to in_session (host-local, same command path). Steam mode without a Steam client ends STEAM_UNAVAILABLE offering offline.
The host-side handshake (protocol/content check before spawn) is `session_host.admit()` from F03.
